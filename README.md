# Video Shorts Maker 1.5

Windows-программа для пакетной подготовки вертикальных роликов из локальных видео.

Она:

- делит каждый исходник на части заданной длины (по умолчанию 60 секунд);
- берёт имя исходного файла без расширения как постоянный заголовок;
- сохраняет результат как `Название — часть 1.mp4`, `Название — часть 2.mp4` и т. д.;
- распознаёт русскую речь локальным Whisper или через Groq API;
- показывает крупные TikTok-субтитры по 2–5 слов и выделяет текущее слово;
- по умолчанию показывает рекламный MP4 поверх продолжающегося видео, временно приглушая основной звук;
- размещает баннер отдельной широкой карточкой по центру над субтитрами, с настройкой размера и высоты;
- по желанию просит Groq выбрать точку максимальной интриги в диапазоне 15–45 секунд;
- сохраняет и прежний режим с полной остановкой ролика как дополнительный вариант;
- использует NVIDIA NVENC, а при любой ошибке автоматически повторяет операцию через CPU;
- сохраняет синхронный AAC-звук и MP4 с быстрым стартом.

Программа работает только с выбранными локальными файлами. Она ничего не скачивает из соцсетей, не обходит DRM и не извлекает защищённый контент.

## Самый быстрый запуск

### Вариант с готовым EXE

1. Откройте папку `VideoShortsMaker`.
2. Запустите `VideoShortsMaker.exe`.
3. Если FFmpeg ещё не вложен в пакет, на вкладке **FFmpeg** нажмите **Установить FFmpeg в папку программы**.

Готовый EXE не требует установленного Python. В переносимый пакет уже включены движки локального faster-whisper и Groq. Сама модель Whisper (`small`, `medium` и т. д.) загружается один раз при первом распознавании и сохраняется в пользовательском кэше.

### Вариант с исходниками (два клика)

1. Установите 64-битный Python 3.10–3.12 с [python.org](https://www.python.org/downloads/windows/). В установщике включите **Add Python to PATH**.
2. Дважды нажмите `Запустить.bat`. Он сам создаст изолированное окружение, один раз установит PySide6 и откроет программу.
3. Нажмите `Установить_FFmpeg.bat` один раз или используйте одноимённую кнопку в программе.
4. Для локальных субтитров один раз запустите `Установить_Whisper.bat`.

Для режима Groq вместо Whisper запустите `Установить_Groq.bat`, получите ключ в личном кабинете Groq и вставьте его на вкладке **Распознавание**.

## Как обработать видео

1. Добавьте один или несколько длинных видеофайлов.
2. Выберите рекламный `banner.mp4`.
3. Выберите папку результата.
4. Проверьте настройки. Для TikTok/Reels подходят:
   - формат **«Весь кадр + размытый фон»**;
   - разрешение `1080x1920`;
   - FPS `30`;
   - качество `high`;
   - баннер **«Поверх продолжающегося видео»**, ширина `88%`, высота центра `58%`;
   - громкость основного видео во время баннера `0.35`;
   - NVENC включён;
   - локальная модель Whisper `small`, устройство `auto`.
5. Нажмите **Начать обработку**.

Первый запуск локального Whisper скачивает выбранную модель. `small` — разумный баланс для русской речи; `medium` точнее, но требует больше видеопамяти и времени. В режиме `auto` программа сначала пробует CUDA. Если в Windows отсутствуют совместимые CUDA 12/cuBLAS/cuDNN-библиотеки, распознавание автоматически повторяется на CPU. Это не влияет на NVENC: аппаратное кодирование видео на проверенной RTX 2070 Super работает отдельно.

## Важные настройки

- **Длина части** — длина исходного материала. В режиме оверлея итоговая длительность не меняется; в режиме остановки увеличивается на длительность баннера.
- **Не делать хвост короче** — короткий остаток добавляется к предыдущей части, чтобы не создавать отдельный ролик на несколько секунд.
- **Момент вставки** — процент от фактической части либо фиксированная секунда.
- **Поверх продолжающегося видео** — основной ролик и речь не останавливаются; баннер появляется отдельной карточкой, а основной звук временно становится тише.
- **Ширина баннера** и **центр по высоте** задают его безопасную зону. Значения `88%` и `58%` рассчитаны на расположение над нижними субтитрами в кадре 9:16.
- **Умный момент Groq** анализирует текст с таймкодами между 15-й и 45-й секундами и ищет фразу перед ответом, эмоциональный пик или развязку. Для этого нужен Groq API key. При недоступном API используется обычная точка вставки.
- Groq выбирает номер одной из готовых точек на границах слов, поэтому строгий JSON больше не используется. При нестандартном ответе программа повторяет запрос и просит вернуть только номер.
- Если оба запроса Groq недоступны, локальный анализ ищет фразу перед раскрытием, вопрос, многоточие или заметную паузу. Середина ролика используется только когда анализировать речь невозможно.
- **Весь кадр + размытый фон** — показывает оригинальное видео полностью и заполняет свободное место мягким фоном. Это новый рекомендуемый режим.
- **Весь кадр + чёрные поля** — показывает оригинал полностью без фонового оформления.
- **Заполнить экран с обрезанием краёв** — старый режим: увеличивает изображение до 9:16 и отрезает боковые края.
- **original** — сохраняет пропорции исходника; выбранное разрешение используется как рамка.
- **Битрейт 0** — режим постоянного визуального качества. Если указать число, оно становится целевым битрейтом в Мбит/с.
- **NVENC** — аппаратный H.264 на NVIDIA. При отсутствии кодировщика или проблеме драйвера программа сама переключается на `libx264`.
- **Отступ субтитров** задаётся от нижнего края в пикселях; он помогает не закрывать интерфейс TikTok.

## FFmpeg

Поиск выполняется в таком порядке:

1. путь, указанный на вкладке **FFmpeg**;
2. `tools\ffmpeg\bin\ffmpeg.exe` рядом с программой;
3. FFmpeg из системного `PATH`.

Автоустановщик скачивает стабильную shared-сборку FFmpeg 8.1 из проекта `BtbN/FFmpeg-Builds` и кладёт нужные EXE/DLL в папку программы. Стабильная ветка выбрана для совместимости NVENC с драйверами RTX 20-й серии. Можно вместо этого вручную указать любую современную Windows-сборку FFmpeg с фильтром `ass/libass` и кодировщиком H.264.

## Сборка EXE

Запустите `Собрать_EXE.bat`. Готовая папка появится в:

```text
dist\VideoShortsMaker\
```

Сборка `onedir` выбрана намеренно: она быстрее стартует и надёжнее работает с FFmpeg, чем один огромный самораспаковывающийся файл.

## Поддерживаемые входы и выходы

Входные контейнеры зависят от FFmpeg: обычно MP4, MKV, MOV, AVI, WebM, M4V и TS, включая разные разрешения, кодеки и FPS. Выход: H.264/AAC MP4, `yuv420p`, стерео 48 кГц.

Если у исходника или баннера нет звука, программа добавляет синхронную тишину. Если у исходника нет аудиодорожки, распознавание для него пропускается.

## Диагностика

- Подробный журнал отображается внизу окна.
- На вкладке **FFmpeg** можно временно включить сохранение промежуточных файлов.
- Настройки хранятся в `%APPDATA%\VideoShortsMaker\settings.json`.
- Если приложение закрыто во время обработки, уже полностью созданные MP4 остаются в папке результата.

```text
shorts_maker/transcription.py  локальный Whisper и Groq

```
